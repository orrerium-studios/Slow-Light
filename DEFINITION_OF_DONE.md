# Slow Light: Definition of Done

A deliverable is done only when every step below has run, its gate report in `gate\` says PASS, JP has viewed it and his words are recorded against the file's hash, and it reached its destination only through the project's install or release script (Scrum Guide 2020, Definition of Done; continuous-integration quality gate).

## Steps and their pass criteria

Step 1 is filled from this project's build pipeline (`.github/workflows/build.yml`). The pass criteria of steps 2 to 5 and the Enforcement section are the template's bar, unchanged. For those steps the Tool column states what this project has, as found on 2026-10-17 in `package.json`, the repository's tests, the assistant's project rules and `docs\DECISIONS.md`: there is no measurement script, no gate script, no script that records JP's view against a file's hash and no release script (`scripts\` holds only `www.js` and `verify_structure.py`), and no hook guards the destinations. So no deliverable meets this Definition of Done until JP rules on those steps in `docs\PROPOSALS.md`.
